# RTS-Zombie

RTS de survie et d'extraction réaliste dans une ville infestée de zombies : on commande une escouade de survivants, avec la vision, le bruit et les blessures de Project Zomboid et la boucle d'expédition d'Escape from Tarkov. Unity 6, rendu 3D pixelisé, vue de dessus.

Le jeu n'est pas encore commencé : le dépôt contient sa direction.
